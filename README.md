## Aufbau der Seite

1. Start: „Wieder Kraft für dich.“ mit Button „Kostenloses Kennenlerngespräch“
2. Energie-Check: sieben Alltagssätze zum Antippen, ausdrücklich keine Diagnose
3. Über mich: ihre Geschichte in der Ich-Form
4. Ablauf: Kennenlernen, Verstehen, Umsetzen, Balance
5. Themen: Hormone und Zyklus, Ernährung ohne Diät, Bewegung, Schlaf und Stress, Mindset, Selfcare und Abenteuer
6. Preise
7. Häufige Fragen
8. Abschluss mit Buchungsbutton

Keine Heilversprechen. Mehrfach steht dort, dass das Coaching keinen Arztbesuch ersetzt.
